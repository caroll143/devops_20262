# Aula 01 — Fundamentos de Git e Docker

## O que aprendi

### Git

- Aprendi a inicializar um repositório utilizando `git init`.
- Aprendi a criar e utilizar branches para separar o desenvolvimento.
- Aprendi a registrar alterações por meio de commits.
- Aprendi a utilizar mensagens de commit seguindo o padrão Conventional Commits.
- Aprendi a fazer merge de uma branch de desenvolvimento na branch principal.

### Docker

- Aprendi o conceito de containers.
- Aprendi a criar uma imagem utilizando um Dockerfile.
- Aprendi a executar um container a partir de uma imagem.
- Aprendi a mapear portas entre o computador e o container.
- Aprendi a utilizar `.dockerignore` para evitar arquivos desnecessários na imagem.

## Comandos Git praticados

```bash
git init
git branch
git checkout -b
git status
git add
git commit
git log
git merge
git push
